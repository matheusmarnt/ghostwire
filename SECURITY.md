# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities privately via [GitHub Security Advisories](https://github.com/matheusmarnt/ghostwire/security/advisories/new) for this repository, or contact the author directly through the public profile at https://github.com/matheusmarnt.

Do not open a public issue for security vulnerabilities.

## Response Time

We aim to acknowledge reports within 5 business days and provide a resolution timeline after initial triage.
