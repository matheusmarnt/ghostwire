# Ghostwire

Automatic runtime skeleton loaders for Livewire — synthesized from your live DOM, zero markup.

## Requirements

| | Supported |
|---|---|
| PHP | 8.2, 8.3, 8.4 |
| Laravel | 11.x, 12.x, 13.x |
| Livewire | 3.6+, 4.x |

The Tier A/B/C compatibility matrix (FR-81) will be published here once the dual-bridge implementation (M1) lands.

## Installation

```bash
composer require matheusmarnt/ghostwire
```
